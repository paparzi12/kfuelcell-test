# 근태 캘린더 (K-FuelCell)

개인별 근태 캘린더 · 주 52시간 관리 대시보드. 단일 HTML 파일이며 GitHub Pages로 바로 배포됩니다.

## 배포 방법

1. GitHub에서 새 저장소 생성 (예: `kfuelcell-attendance`) — Public 또는 Pages 사용 가능한 Private
2. `index.html`, `README.md`, `근태업로드_양식.xlsx` 업로드 후 커밋
3. 저장소 → **Settings → Pages** → Source를 `Deploy from a branch`, Branch를 `main / (root)`로 지정하고 저장
4. 1~2분 뒤 `https://<계정명>.github.io/<저장소명>/` 으로 접속

수정할 때는 `index.html`을 교체 커밋하면 자동 재배포됩니다.

## 계산 기준 (집중근무제)

- 소정근로: 월·화·목 9h / 수 7h / 금 6h / 토·일 0h = 주 40h
- 휴게 자동 공제: 점심 11:00~12:00, 저녁 18:00~18:30 (근무시간과 겹치는 만큼)
- 연장근무 = 실근로 − 해당 요일 소정근로 (연차 1일 / 반차 0.5일 / 반반차 0.25일만큼 소정 차감)
- 주 52시간 = 일~토 실근로 누계. 초과되는 요일부터 캘린더 적색 표시
- 센싱 누락 시 요일별 기준시각(08:00 ~ 종업시각) 자동 적용, 해당 칸에 `*` 표시

기준값은 관리자 화면 **기준 설정**에서 변경할 수 있습니다.

## 현재 제약 — Firebase 전환 전

데이터가 **접속한 브라우저의 localStorage에만** 저장됩니다.

- 관리자가 업로드한 근태가 직원 PC에는 보이지 않습니다
- 직원이 작성한 소명이 관리자에게 전달되지 않습니다
- 브라우저 캐시를 지우면 데이터가 사라집니다

전사 운영을 하려면 Firebase(Firestore + Auth) 연결이 필요합니다. 그 전까지는 관리자 1인이 자기 PC에서 집계·확인하는 용도로 사용하십시오.
